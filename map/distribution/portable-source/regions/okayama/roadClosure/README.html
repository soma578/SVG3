内容

viewer.html は単体確認用、Container.svg はSVGMapへ読み込む入口です。viewer-isolated.html と Container.isolated.svg はS-LaWA確認用です。

確認方法

ZIPを展開し、このフォルダーをHTTPサーバーで公開して viewer.html を開きます。ブラウザーの制約があるため、ファイルを直接開かずHTTP経由で確認してください。

別のSVGMapへ組み込む

フォルダー構成を保ったまま配置し、Container.svg 内の <animation> 宣言を組み込み先Containerへ追加してください。相対パスの基準が変わる場合は xlink:href を配置先に合わせて調整します。
