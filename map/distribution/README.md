# Portable artifact distribution

`portable/index.json` is the same-origin artifact catalog generated by `npm run portable:bundle`.

External catalogs must be signed with an Ed25519 private key. Private keys must not be stored in this repository.

```bash
npm run portable:index:sign -- \
  --index ../map/distribution/portable/index.json \
  --output /path/to/publish/index.json \
  --key /secure/path/publisher-ed25519-private.pem \
  --key-id publisher-key-2026 \
  --publisher-id svg3
```

The receiving portal administrator registers only the matching public JWK in
`trusted-publishers.json`.

```json
{
  "keyId": "publisher-key-2026",
  "publisherId": "svg3",
  "algorithm": "Ed25519",
  "enabled": true,
  "publicKeyJwk": {
    "kty": "OKP",
    "crv": "Ed25519",
    "x": "base64url-public-key"
  }
}
```

External catalogs are rejected when the signature, expiry, publisher identity,
bundle manifest hash, or Container hash does not match. External layers are
mounted in isolated mode.
